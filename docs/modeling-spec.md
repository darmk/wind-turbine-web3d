# 建模规范与精度

模型单位为米。Blender +Z 向上，转子轴 +X；glTF 标准导出转换 `(x,y,z) → (x,z,-y)`，Web +Y 向上，转子轴仍 +X。不再给根节点附加 90° 修正。轮毂中心位于 Blender `(6.4,0,130)`，其中 overhang=6.4 m 为工程估算；Web 为 `(6.4,130,0)`。

统一配置 rotor_diameter_m=181.1，blade_length_m≈89，根部径向基准=1.55 m。三片叶片绕 +X 等间隔 120°。叶片 9 个参数控制站经平滑插值生成 100/64/32 个展向细分，翼型由闭合 NACA-like 厚度表达式与根部圆截面混合，具弦长、厚度、扭转、后掠、渐缩。最后 6% 展向约束扫掠叶尖半径不超过 90.55 m。

**叶片几何为基于公开长度、公开外形资料和工程合理性的视觉高保真近似模型。** “约89m”为用户提供名义设计值，本次已读厂家/政府资料未披露精确翼型及长度工程图，不能把脚本截面称为 EN89 原厂翼型。

塔筒以四段薄壁锥管、分段硬边、法兰与共享网格螺栓构成。内部含四层平台、连续梯子和电缆。塔段上端由轮毂高度推导，改为 140 m 时保持叶轮和传动链高度一致。分段数、直径、壁厚与法兰尺度为估算，不可用于有限元或制造。

轮毂包含壳体、三个安装接口、变桨轴承、简化驱动电机。机舱以 superellipse 截面放样形成有厚度的流线外壳，包含检修舱口、百叶及风向仪。Nacelle_Cover 与 Hub_Shell 设置 shell 元数据供透明管理识别。

机舱内部包括主机架、主轴、双列滚子主轴承、两行星一级斜齿、联轴器、发电机、液压盘式制动示意、变流器、控制柜和冷却单元。每级行星包含太阳轮、三个行星轮、齿圈内齿与行星架。齿廓非精确渐开线，齿数/模数不是厂家数据。发电机包含外壳、转子、轴、端盖、铜绕组与散热筋。

材质采用无贴图 PBR：TurbineWhite、TurbineGray、Metal、DarkMetal、Rubber、Glass（预留）、Cable、Copper、IndustrialBlue、WarningYellow。金属粗糙度/颜色为视觉设计值。没有品牌 Logo 或贴花。

LOD0 径向64/叶片100×48；LOD1 径向40/叶片64×32；LOD2 径向20/叶片32×16。微小滚子使用有限细分；法兰螺栓共享 Blender mesh，Web 按同父级、同几何合为 InstancedMesh。梯子、散热片与不能单独选择的细节按组件/材质批处理。保留24个统一语义组件，不合并跨部件语义。Detail 独立包含 Bolts、Flanges、Platforms、Ladders、Handrails 检修附件层级。

所有 Mesh 应用旋转/缩放；保留命名 Empty 的安装姿态与转子旋转支点，不能把组旋转清零而破坏装配坐标。命名 Empty 是有效层级，不视为损坏空几何。网格法线重算，环形硬边分离，平面 UV 备用；当前没有纹理贴图，因此不依赖 UV 质量。GLB 默认启用 Draco position16bit/normal10bit；解码器随项目本地提供。源码保存 LOD0，LOD1/2 可重新生成。
